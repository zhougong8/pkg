# 央视 / 卫视 直播源列表

央视频 CDN 中转的央视及卫视 HLS 直播源。**无需 vkey、无需鉴权**，播放器直接可播。

## 文件说明

| 文件 | 格式 | 说明 |
|---|---|---|
| `all.m3u` | M3U | 完整播放列表，42 个频道（央视 11 + 卫视 31），带 `group-title` 分组 |
| `all.txt` | `频道名,URL` | 供只支持 TXT 列表的播放器 |
| `cctv.txt` | `频道名,cnlid` | 仅央视 11 个频道的频道编号 |

## 电视启动页

用电视浏览器（如 TV Bro）直接打开，方向键选台、确认键跳转：

```
https://zhougong8.github.io/cctv-playlist/
```

说明：该页是**启动页**，共 73 个央视频频道（央视 21 + 卫视 33 + CGTN 6 + 特色频道 13），点击后跳到央视频官方页面 `yangshipin.cn/tv?pid=…`。带 `VIP` / `限免` 标记的频道需登录央视频账号。

中转 HLS 流走的是 `http://`，在 `https://` 页面里会被浏览器的混合内容策略拦截，所以不能在这一页里直接播放——要看中转流，请用播放器加载下面的 `all.m3u`。

## 已知限制

**该中转缺少以下频道**：CCTV-6 电影、CCTV-11 戏曲、CCTV-12 社会与法、CCTV-14 少儿、CCTV-15 音乐、CCTV-16 奥林匹克、CCTV-16 4K、CCTV-17 农业农村。

同一频道通常有多个 cnlid 后缀变体（`01` ~ `09`）。实测规律：

- 后缀 `01` / `02` / `03` 常为 **SM4-CBC 加密**（清单含 `#EXT-X-KEY:METHOD=SM4-CBC`），普通播放器无法解码；
- 后缀 `04` / `05` 虽为明文，但多数只有**纯音频**（分片中无 H.264 关键帧）；
- 判断是否可用，必须同时满足：清单中无 `#EXT-X-KEY`，且分片含 `00 00 01 67`（H.264 SPS）。

部分频道的原始编号为 404，已替换为可用编号：CCTV-4 → `2029797101`、CCTV-8 → `2029793001`、CCTV-13 → `2029797201`。

源地址为第三方中转，**稳定性与可用性不保证**，随时可能失效。
